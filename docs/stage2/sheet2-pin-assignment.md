# Sheet 2: FPGA pin assignment (LCMXO2-4000HC-4TG144, revision A2)

Generated by `tools/fpga/pinplan.py` from the Lattice pinout data (facts-only extract of the MachXO2-4000 Pinout rev 1.5, [V S63]) and the plan in that script.

- **C-30, owner approval 2026-11-19:** the Rev 1 FPGA is the **LCMXO2-4000HC-4TG144C** (the design no longer fits the 2000HC). The G-SHEET2 assignment, made on the 2000HC, is kept pin for pin; the 4000HC-only pads 31, 63 and 103 (NC on the 2000HC) are kept free.

- Every bank runs at VCCIO 3.3 V, and every port is LVCMOS33 (`z2_top.lpf`).
- **Reserved, no signal:** PROGRAMN 119, INITN 110, DONE 109 (configuration, `SDM_PORT`); TMS 130, TCK 131, TDI 136, TDO 137 (JTAG); JTAGENB 120 (C-19).
- **Signals:** 101. **Spare pads:** 6 bank 1: 103, bank 2: 63, 67, bank 3: 31, bank 4: 23, 24.
- **S4-3, owner approval 2026-11-19 (authorised exception to the freeze):** RP_SCK moved from pin 1 to pin 5 (PCLKT5_0, primary-clock input for the SCK-clocked SPI slave); RP_IRQ_N moved from pin 5 to pin 1.
- **C-26 (option C-17b), owner approval 2026-11-19:** the FAULT LED moved to the RP2040, so pin 67 is spare. Every other pin is unchanged from the G-SHEET2-approved assignment (`tools/fpga/pins_gsheet2.csv`; `pinplan.py` fails on any other difference).
- **Pin compatibility with the LCMXO2-2000HC** (the G-SHEET2 basis), checked against the MachXO2-2000 pinout rev 1.2 [V S63]:
  every assigned pin is an I/O pad in the same bank there too, and PROGRAMN, INITN, DONE, JTAGENB, TMS, TCK, TDI, TDO, SN,
  PCLKT0_1, SDA and SCL are the same package pins. The pad names differ (column *2000 pad*); the LPF uses pin numbers.
